Hướng Dẫn Đăng Truyện

1. Thêm bộ truyện mới

Vào tab Quản Lý Truyện -> chọn Thêm Truyện Mới để điền tên truyện, tác giả, mô tả tóm tắt và chọn ảnh bìa phù hợp.

2. Đăng chương mới

Vào tab Quản Lý Chương -> chọn bộ truyện bạn muốn viết -> bấm Thêm Chương Mới để điền tiêu đề và nội dung chương chữ.

3. Xem trực tuyến

Khi bạn nhấn Lưu, hệ thống tự động đồng bộ truyện lên GitHub. Hãy truy cập trang đọc truyện của độc giả để xem chương mới hiển thị tức thì!

Cấu hình kết nối dữ liệu GitHub

Cung cấp Token GitHub để trang Admin này trực tiếp gửi yêu cầu lưu trữ và sửa đổi danh sách truyện trên Kho chứa (Repository) GitHub của bạn.

Token cần có quyền ghi đè tệp tin (quyền contents: write). Mã token này được lưu trữ cục bộ bảo mật trên trình duyệt của bạn.

Xuất Dữ Liệu Local (Backup)

Tải xuống toàn bộ dữ liệu truyện và chương hiện tại dưới dạng tệp tin cấu hình JSON. Bạn có thể lưu trữ file này trên máy tính cá nhân.

Nhập Dữ Liệu Đè (Restore)

Khôi phục hoặc ghi đè dữ liệu hiện tại bằng tệp tin JSON đã sao lưu trước đó. Lưu ý: Thao tác này sẽ thay thế dữ liệu hiện có trong localStorage.
